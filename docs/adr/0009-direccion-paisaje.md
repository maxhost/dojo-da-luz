# ADR-0009 — Dirección oficial de paisaje

## Estado

Aceptada. Supersede las direcciones visuales comparativas 0004–0008. La arquitectura de
cinco pantallas se mantiene.

## Decisión

Diseño C es el único prototipo vigente. Inicio narra sol → montaña → tierra → dojo →
umbral. Clases hereda tierra y trayecto; Aikido, montaña y camino; Dojo, estructura y
transmisión; Contacto, umbral. Las formas SVG son estáticas, decorativas y subordinadas
al contenido.

La home muestra Benfica y Lumiar. Encarnação se conserva en Clases y Contacto para no
eliminar silenciosamente la sede ni sus términos SEO; no aparece en Inicio.

## Consecuencias

Se retiran A, B y el selector. `/mockup/` contiene la dirección elegida. La migración a
la home productiva y JSON queda como trabajo posterior.
